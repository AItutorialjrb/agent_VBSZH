## 3. Signal definition
**Process (sample `S_EW_WHjj`, idx 1):**
```
define p = g u c d s b u~ c~ d~ s~ b~          # 5F proton
define j = g u c d s u~ c~ d~ s~               # 4F jets: NO external b in the final state (see §3.1)
generate p p > w+ h j j QCD=0 QED=4, w+ > l+ vl      (l = e, mu)
add process p p > w- h j j QCD=0 QED=4, w- > l- vl~
```
The complete set of tree diagrams at (0,4) for each external state is kept and summed coherently: VBF-type W/Z fusion, radiation off the quark lines, and **Higgsstrahlung-like triboson configurations W V H with V→qq̄′** (s-channel W/Z). "VBS/VBF-like" is a later *fiducial region* in m_jj, Δη_jj, not a diagram subset; no diagram is removed. The W is on shell (narrow-width decay chain, Breit–Wigner cut-off 15 Γ_W), which keeps the W spin correlations to the decay leptons; the off-shell (0,5) ℓνHjj sample `S_EW_WHjj_offshell` (idx 3) measures the pole approximation and is never added (result in 03 §2).

### 3.1 Jet flavour: resonant tHq inside the 5F EW amplitude (finding; decision D-WH-1)
With b quarks allowed as external jets, the (0,4) W⁺Hjj amplitude contains q b → q′ t H, t → W⁺ b, i.e. **resonant tHq production is part of "EW WHjj"** (q b → q′ t is (0,2), t→Wb and the H emission add one each). This has no ZH analogue. Measured (undecayed W, same cuts, `work/xsec/*status.txt`):

| Jet definition | σ(W±Hjj) [fb] | ratio to 4F |
|---|---|---|
| 4F jets (j without b) — **provisional signal** | 61.37 ± 0.59 | 1 |
| 5F jets (j with b) | 127.7 ± 2.1 | 2.08 ± 0.04 |
| 5F jets, on-shell t/t̄ removed (`$ t t~`) | 64.07 ± 0.61 | 1.044 ± 0.014 |

A naive 5F definition would therefore double the "signal" with resonant tHq, which is also a separate background sample (`H_tHq`) → double counting. Options:
1. **4F jets (provisional, used below):** gauge invariant (selection of external flavours), no top resonance, no overlap with tHq/ttH. Loses the non-resonant b-jet complement (WZH with Z→bb̄, b-quark VBF): 4.4 ± 1.4 % of σ, mostly removed later by the b-veto. Quoted as a signal-definition uncertainty.
2. 5F with `$ t t~`: keeps the complement but removes a phase-space region of a coherent amplitude (not strictly gauge-invariant, standard DR-type prescription).
3. 5F full, with tHq background dropped: physically mislabels single-top-Higgs as VBS signal.
Human decision requested (D-WH-1); recommendation: option 1.

Initial-state b (5F proton) is kept: without a final-state b, b-initiated contributions are b b̄ → W H jj (non-resonant t-channel top only). Diagram/process audit (`work/genonly/*.log`, MG5 generate output, W⁺ / both charges):

| Card | orders | processes (W⁺ / W±) | diagrams (W⁺ / W±) |
|---|---|---|---|
| `S_EW_WHjj_nodec` | (0,4) | 42 / 84 | 756 / 1512 |
| `H_QCD_WHjj_nodec` | (2,2) | 50 / 100 | 180 / 360 |
| `C_WHjj_nodec` (QCD≤2, QED≤4) | coherent | 50 / 100 | 936 / 1872 |
| `I_WHjj_nodec` (QCD²==2, QED²==6) | interference | 42 / 84 | 872 / 1744 |
| `S_EW_WHjj_5Fj_nodec` (= `_notop`) | (0,4) | 52 / 104 | 896 / 1792 |

Order closure at diagram level: 756 + 180 = 936 = C (exact); EW processes ⊂ QCD processes (the 8 extra QCD processes are gluon-initiated/-final, which exist only at QCD order 2); interference set = 756 EW + 116 QCD diagrams on the 42 common processes. `$ t t~` removes no diagram (on-shell region only), as expected.

## 4. BR ledger (applied exactly once per sample; asserted in `make_cards.py`)
| Factor | Value | Definition / source |
|---|---|---|
| BGG | 0.002270 | B(H→γγ), LHCHWG YR4, mH = 125 GeV (same as ZH) |
| B_MG5(W→ℓν) | 0.111137 per flavour | Γ_tree(W→ℓν) = g²M_W/(48π) = 0.227564 GeV with the model's α, s_W² = 0.222246; / Γ_W(param card) = 2.0476 GeV |
| B_PDG | e: 10.71 ± 0.16 %, μ: 10.63 ± 0.15 %, τ: 11.38 ± 0.21 % | PDG 2025 W listing, archived `wh/reports/sources/pdg2025_w.{pdf,txt}` (lines 326–329) |
| **WF** | **0.9601** = (B_e+B_μ)/(2·B_MG5) (per flavour 0.9637 / 0.9565) | MG5-LO→PDG W→eν+μν factor (analogue of ZH ZF = 0.9783) |
| WF_tau | 1.0240 | for the W→τν feed-down sample |

Accounting contract: σ_phys(signal) = σ_MG5(pp→W±Hjj, W→eν/μν) × WF × BGG. Pythia forces H→γγ with conditional BR = 1 and does not fold B(H→γγ) into its σ (verified in 03 §3: σ_PY8 = σ_LHE), so BGG enters once, externally. Lepton-universal PDG B(W→ℓν) = 10.86 % would give WF = 0.9771 (+1.8 %); the per-flavour choice follows the ZH per-flavour Z convention and the difference is quoted as a normalisation systematic.

Signal at generator level (03 §1): σ(W→eν/μν) = 13.83 fb → σ×WF×BGG = **0.0301 fb → 15.1 events at 500 fb⁻¹ before any acceptance** (LO). The charge split W⁺/W⁻ is measured from the test-job LHE (03 §4).

## 5. QCD W±Hjj — definitions (a) and (b) — and interference
| Component | Card | σ (W undecayed) [fb] |
|---|---|---|
| EW (0,4) | `S_EW_WHjj_nodec` | 61.37 ± 0.59 |
| QCD (2,2) | `H_QCD_WHjj_nodec` | 265.8 ± 1.5 (4.33 × EW) |
| Interference O(α_s α³) | `I_WHjj_nodec` | −0.256 ± 0.014 (−0.42 ± 0.02 % of EW) |
| Coherent sum C | `C_WHjj_nodec` | 317.0 ± 2.3 |

- **Definition (a), primary:** signal = EW (0,4) only; QCD W±Hjj (`H_QCD_WHjj`, W→eν/μν, σ = 58.75 ± 0.14 fb) is a resonant background fitted with the signal m_γγ shape; the signed interference is a separate, signed component (never unweighted events).
- **Definition (b), inclusive-signal variant:** signal = |M_EW + M_QCD|² = C. Used only as a variant (reported alongside), because the QCD part does not probe the HVV coupling structure that motivates the study.
- **Interference statement:** at generator level the EW×QCD interference is −0.42 % of EW (colour suppression: the interfering amplitudes must share the colour flow). It must be re-evaluated in the VBS region (Phase 05) before it is neglected; it is carried as a signed term.
- **Order closure EW + QCD + I = C:** first pass 326.9 ± 1.6 vs 317.0 ± 2.3 fb (pull 3.5, −3.0 %) with 500-event integration targets. Diagram closure is exact, so this is either an integration-precision effect or a real effect. A repeat at a 10× event target with independent seeds is in 03 §2 (HP_CLOSURE_RESULT).

## 6. H→γγ implementation
There is no tree-level HAA vertex in `sm`. H is left undecayed in the LHE and decayed in Pythia8 (`25:onMode off`, `25:onIfMatch 22 22`, `HiggsSM:NLOWidths on`; `wh/cards/py8_wh_haa_dipole.cmnd`, dipole recoil for the VBS topology as in ZH; `py8_qcd_wh_haa.cmnd` global recoil for QCD WHjj; `py8_top_haa.cmnd` for top samples). Physical BGG is applied once (§4). Closure: 03 §3.
